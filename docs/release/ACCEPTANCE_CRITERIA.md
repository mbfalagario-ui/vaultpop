# Monetized iOS Acceptance Criteria

| Area | Criterion |
|---|---|
| Launch | First paint has no blocking network call, permission prompt, or ad. |
| Gameplay | All three modes work offline through Results with pause and restart. |
| Shop | Six exact StoreKit products, specified order, clear fixed grants, prices, and renewal disclosure. |
| Transactions | Server-verified, fail-closed, exact-once grants with persistent entitlements. |
| Restore | Restores Ad-Free Upgrade and active VaultPass without restoring consumed consumables. |
| Economy | Purchased Vault Coins and boosters do not expire; no paid randomness. |
| Ads | Exact AdMob IDs, allowed placements only, contextual default, all paid suppression rules. |
| Support | Private category/message/optional-email form, disclosed metadata, backend plus mail fallback. |
| Privacy | Ads, purchases, support, identifiers, and device context accurately disclosed. |
| Compliance | No real-value mechanics, external payment, gambling, prize, or promotional financial claims. |
| Secrets | Tokens and private keys remain outside git and command output. |
| Build | iOS production profile only; no Android and no automatic App Review submission. |
